# カメラと ArUco マーカーの準備

床を斜め上から撮るカメラ 1 台で、画素を床の位置（cm）に直す。そのための校正と、ロボットの位置と向きを読むマーカーの準備。
マーカーの決まりは `config/markers.yaml`、校正の結果は `data/calibration/camera.yaml`。

## 1. 印刷する

```bash
uv run python scripts/make_markers_pdf.py --out data/generated/markers
```

- `markers_a4.pdf`: 床の 4 隅（1 ページ目、ID 0〜3、黒い四角 60 mm）とロボットの上（2 ページ目、ID 4、50 mm）。
- `charuco_a4.pdf`: カメラのレンズ（焦点距離・歪み）を測るボード（6 × 8 マス、1 マス 25 mm）。
- **実際のサイズ（100%）で印刷する**（「用紙に合わせる」にしない）。黒い四角の 1 辺とボードの 1 マスを定規で測り、60 mm・
  25 mm からずれていたら測った値を `config/markers.yaml` に書く。
- ボードは厚紙や板に平らに貼る（反っているとレンズの値がずれる）。

## 2. 床にマーカーを置く

- 作業領域は床の上の長方形で、4 隅にマーカーを置くと大きさも決まる（学習した範囲の 0.6〜1.0 m 四方に収める）。
  「手前」はカメラに近い辺。
- 紙を黒い四角の 5 mm 外側の線で切る。マーカーの向きは問わない。
- **奥の 2 つ（ID 2・3）** は作業領域の **内側** に、紙の 2 辺を角の 2 辺に合わせて置く。
- **手前の 2 つ（ID 0・1）** は作業領域の **外側**（カメラ側）に、紙の角を作業領域の角に合わせ、手前へはみ出させて置く。
  斜め上のカメラから見て、マーカーが作業領域を隠さないようにするため。

```
   ┌─────────────────────┐   ← 奥
   │■ID 3          ID 2■│   ← 内側の角
   │                     │
   │      作業領域        │
   │                     │
   └─────────────────────┘   ← 手前
    ■ID 0          ID 1■     ← 外側（カメラ側）
```

- 壁は置かない（`config/markers.yaml` の `wall_thickness_m: 0`）。
- 4 隅のマーカーは校正のときだけ要る。校正の後は外してよい。カメラを動かしたら、置き直して校正し直す。
- ロボットの上には ID 4 のマーカーを、車体の中心に水平に貼る（高さ 65 mm、`robot_marker_height_m`）。

## 3. カメラを置く

- USB の web カメラ（開発では Logitech C920）を、作業領域全体と 4 隅のマーカーが入るように斜め上に固定する。
- **解像度は 1920×1080、10 fps**（`config/field.yaml` の `camera`。カメラが受け付けた値を読み返し、違えば止まる）。
  1280×720 では奥のマーカーが潰れて読めなかった。
- 校正の後は **カメラを動かさない。ズーム・ピント・解像度も変えない**（変えたらレンズから測り直す）。
- カメラはハブを通さず MacBook に直接つなぐ。ハブ経由では、途中で映像が来なくなることがあった。

## 4. 校正する（話しかける画面のアプリの /calibrate）

話しかける画面のアプリ（[real_robot_runbook.md](real_robot_runbook.md) の 3）を起動し、http://localhost:8080/calibrate を開く。
校正・背景・マーカーの向きが揃っていなければ、アプリは実機に切り替えられない状態（2D シミュレーションとこの画面）で起動する。校正だけをしたいときは次でもよい:

```bash
uv run python scripts/calibrate_app.py --port 8082   # http://localhost:8082/calibrate
# 前に撮ったボードの写真から、レンズの値を求め直す
uv run python scripts/calibrate_app.py --port 8082 --board-photos data/camera/<日時>
```

1. **レンズ（カメラ・解像度・ズーム・ピントを変えたときだけ）:** ボードを手に持って 15〜20 枚撮る。画面のいろいろな場所
   （四隅、端、中央）、いろいろな傾き（正面、上下左右に 30〜45°）、いろいろな距離で、止めて撮る。再投影誤差の平均の目安は
   0.5 px 以下。
2. **床:** 作業領域に何も置かずに撮る。4 隅の ID が揃うと、カメラの位置と向きと作業領域の大きさが決まる（4 隅のどれかが
   見えなければ保存しない）。誤差の目安は 1〜2 px（床で 1〜2 mm）。
3. **確かめて保存:** 映像に重ねた作業領域の枠・10 cm の格子・ゴールの枠が床の印と合うかを見て保存する。保存のときに
   背景（物もロボットも無い床）も撮る。前の校正は `data/calibration/history/` に残る。

学習した範囲の外の大きさや、ロボットが画像の外にはみ出してしまう置き方なら、保存を断る。照明が大きく変わったときも、
物とロボットをどけて背景を撮り直す。

## 5. ロボットのマーカーの向きを測る

ID 4 を貼った・貼り直したときだけ。ロボットを作業領域に置き、前進と後退を交互にさせて、マーカーの向きとロボットの前の
ずれを測る（`data/calibration/robot_marker.yaml` に保存される）。カメラを開くので、アプリは止めておく。

```bash
uv run python scripts/measure_motion.py yaw
```
